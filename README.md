The single-line safety warning label that should come printed on every human being — funny first, plausible second. One program, one line, no dependencies: `main.ts` writes the label to `/output/entry.txt`.

> WARNING: Contents: one human, mostly water, held together by caffeine and deadlines. DO NOT shake, microwave, or ask why the fridge light is on at 3 a.m.

Run it with Node 22:

```sh
node main.ts
```
